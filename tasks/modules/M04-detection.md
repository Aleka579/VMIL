# M04 Windows 检测

- 版本：v0.1。
- 源码归属：Windows、Core/Evidence。
- 当前状态：采集与解释实现、故障/误判测试通过；真实采集待 M05 入口验证。
- 入口：[模块架构](../../docs/MODULES.md)、[验收索引](../PROGRESS.md)、[工作日志](../../WORK_LOG.md)。

## 目标

五类只读采集提供可解释证据和分项失败状态。

## 前置条件

M00、M01；当前宿主 OS 仅核实实际 API 兼容性。

## 具体子任务与实现步骤

- [ ] 实现 SMBIOS、CPU、PnP、Tools、系统信息五类观测。
- [ ] 每项记录来源、时间、状态与解释；异常/超时/权限不足正常降级。
- [ ] 区分 Hypervisor、VMware 客户机证据与 Tools 软件痕迹。
- [ ] 普通权限采集，默认不采集用户名、序列号、UUID、MAC 等标识。

## 自动化测试与实际验证

合成证据误判与故障测试；宿主机只读采集和独立系统信息对照。

执行记录包含命令、目录、时间及时区、结果、失败原因与修复情况；未执行不标通过。证据分类沿用 [测试计划](../../docs/TEST-PLAN.md)。

## 验收标准

DET-01、DET-02、DET-04、DET-05；真实客户机结果由 M06 验证。

## 风险与回滚方案

不提权、不安装驱动、不修改安全设置；取消与失败可见。 发生 Defender 拦截立即停止对应操作，遵守项目禁令。

## 完成状态与下一步

- 已完成：WindowsCollector、NativeWindowsDataSource、EvidenceEvaluator；五类/14 项观测、状态/时间/来源、超时/取消与多来源解释。
- 验证：Release 构建 0 警告/0 错误；累计单元 43/43、临时文件/合成流程 8/8，证据 artifacts/test-results/m04/。
- 资源：一次只运行一个原生查询；WMI 查询设 2 秒超时，类别等待 5 秒；后台原生调用不能保证即时终止，后续调用仍受单查询门控。
- 下一步：M05 共享引擎入口进行宿主机实际采集；客户机由 M06 按授权验证。
