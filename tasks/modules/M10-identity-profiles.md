# M10：身份实验计划与预览

## 目标

把支持依据、目标版本、拟变更、验证与恢复要求组织成可审查的实验计划。此模块只生成预览，不执行配置。入口：[v0.3 计划](../../docs/V03-PLAN.md)。

## 前置条件

M09 的来源、状态和隐私契约已验证；M08 能力矩阵仍有效。没有逐字段支持依据的候选可以展示缺口，但不能生成可执行写入授权。

## 具体子任务

- 记录目标产品/构建、字段语义、值约束、官方来源、风险、实际验证状态及恢复范围。
- 优先在已有预览模型内表达，不预建插件或任意脚本配置语言。
- 只允许显式登记的实验项；禁止导入物理机标识作为冒充模板。
- 不提供隐身预设、未经验证参数集合或自定义名称/值写入器。

## 实施步骤

1. 用合成 MAC 唯一性/UUID 生命周期样例设计计划，标为不可执行候选。
2. 生成逐项差异、影响、准入失败理由和恢复说明。
3. 在既有配置/报告页面呈现预览；旧预览遇到目标、状态或内容变化即失效。
4. 若需要保存计划，限定版本和字段，不执行导入内容，不保存凭据或原始私有标识。

## 自动化测试

验证未知字段、版本错配、非法值、歧义和不完整依据被拒绝；计划保存仅在确有实现需要时测试格式兼容及不可信输入。使用合成数据，不能触发 VMware 写入。

## 验收标准

- [x] 每项计划可以追溯到版本、依据、风险和恢复范围。
- [x] 未验证候选不可执行，预览明确显示准入缺口。
- [x] 不接受任意 VMX 参数、脚本或物理机身份复制。
- [x] 预览变化使旧确认失效；敏感值默认不进入导出。
- [x] 模拟测试通过，报告保留“计划未执行”状态。

## 风险与回滚方案

主要风险是将预览误认为修改成功或把模板当授权。状态必须显式，执行资格交由 M11 重新核实。回退只涉及项目代码/合成计划，不修改真实 VM；保留用户已有计划文件。
