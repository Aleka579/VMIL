## 目标

交付普通用户能够操作的界面和宿主机/客户机报告流程。

## 前置条件

- 采集引擎、报告模型与 VMX 读取已具备适用测试。
- 两份合成报告用于UI和比较开发；宿主机版本不设门槛，客户机允许Windows 10/11 x64，按具体Build实测，版本入口为docs/DEPENDENCIES.md。

## 具体子任务与实施步骤

- [ ] 实现概览、检测详情、配置查看、报告对比、报告导出五个基本页面。
- [ ] 使用 MVVM 组织界面，采集和文件操作在后台运行，支持取消并展示部分失败。
- [ ] 支持选择 VMX 和导入两份 JSON 报告；不默认扫描用户全部存储设备。
- [ ] 对比相同字段、统一单位并保留采集状态差异；已脱敏或缺失字段不判成真实硬件差异。
- [ ] 导出默认脱敏 JSON 与静态 HTML，所有来源字符串正确编码，HTML 不加载远程资源。
- [ ] 提供中文界面和英文资源；采集模式共享引擎，避免单独维护另一套检测逻辑。

## 自动化测试与人工验证

- 验证两份合成报告的导入、对比、异常格式和未支持报告版本处理。

- 人工运行 UI 检查响应、取消、普通用户权限和中英文资源；仅编译不能代替 UI 实测。
