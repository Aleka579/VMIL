## 本轮测试入口修正

原接入工具未提供加密 VM 的 `-vp` 选项。本机 vmrun 帮助确认支持后，增加显式 `--prompt-vm-password`，使用不保存凭据的 Windows 原生窗口；不提取已保存密码、解密密钥或系统凭据库。两类密码仅用于本次内存/短暂原生认证参数，并对返回输出同时脱敏；不声称 Python 字符串可完全擦除。

首次部署的413文件及 ZIP 校验已成功，但环境查询0013的 WMI 筛选参数多带了一层反斜杠引号，测试脚本退出1。原命令、结果与 traceback 均保留；改为独立 `context` 读取阶段，在确认旧队列无待执行项后仅运行已修正查询0015并取回0016，实际通过6项部署检查。没有重放原失败命令或重新部署产品，该问题不属于产品原包失败。

原 Win10 独占输出和旧测试队列保持原范围。本轮使用可复用 `tools/mcp/guest_acceptance.py` 的明确案例路径，复用原产品 ZIP、同 CI 驱动和已有夹具，只新建42,208字节的路径化合成输入。
