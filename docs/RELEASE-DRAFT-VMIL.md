## 拟发布说明

VM Identity Lab是Windows/VMware Workstation诊断与有限配置管理工具，提供五类虚拟化特征采集、VMX声明查看、宿主/客户机报告对比及脱敏JSON/HTML导出。支持中英文界面，普通权限运行，自包含包无需开发SDK或系统.NET；无遥测或自动上传。

配置管理先显示目标、逐项差异和影响，经新确认后核实完全关机/占用/原内容，备份原始字节，再通过官方API应用和复核。历史记录在退出重开后可读取；恢复只反向修改本次参数，保留其他内容。结果未确认会保留pending及备份并阻止重放。

唯一已批准的可写范围：Workstation登记版本17.5.2.23775571、hardware19、每插槽2核；内存4096↔6144MiB、vCPU2↔4。App不控制电源，不直接替换VMX，其他版本/拓扑/数值保持拒绝。配置备份不是整机备份，本地租约不是VMware全局锁。
